# 📊 Time Series Forecasting using ARIMA

## 📌 Overview

This project focuses on time series analysis and forecasting using the ARIMA model. The dataset represents monthly airline passenger data, which is used to analyze trends, seasonality, and future predictions.

---

## 🎯 Objectives

* Perform time series analysis
* Identify trend and seasonal patterns
* Build ARIMA forecasting model
* Evaluate model performance using RMSE

---

## 📂 Dataset

The dataset used is the Airline Passengers dataset, containing monthly passenger counts.

* Source: Public dataset (loaded via URL)

---

## ⚙️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Statsmodels
* Scikit-learn

---

## 📈 Methodology

1. Data preprocessing (Datetime conversion, indexing, frequency setting)
2. Visualization of time series data
3. Seasonal decomposition
4. Train-test split
5. ARIMA model building
6. Forecasting with confidence intervals
7. Model evaluation using RMSE

---

## 📊 Results

* Successfully forecasted future passenger values
* Achieved reliable prediction accuracy
* Visualized forecast vs actual values with confidence intervals

---

## 🚀 How to Run

1. Clone the repository
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
3. Run the notebook in Jupyter or Google Colab
